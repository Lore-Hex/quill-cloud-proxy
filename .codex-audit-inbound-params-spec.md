# Task: enclave audit batch A — stop/sampling/reasoning inbound params

Enclave (`enclave-go`). Fixes the HIGH+MEDIUM inbound-param drops from
quill-router#130. BUILD + TEST ONLY — no commit/push/deploy. Do not touch
`.codex-*` files. Read the audit issue context below; ground each change in the
cited file.

Principle: a documented client sampling/stop/reasoning param must reach the
provider (or be explicitly rejected), never silently no-op.

## 1. `internal/types/types.go` — `OpenAIChatRequest` new fields

Add (JSON tags exact):
```go
Stop               any      `json:"stop,omitempty"`             // string | []string
Seed               *int     `json:"seed,omitempty"`
FrequencyPenalty   *float64 `json:"frequency_penalty,omitempty"`
PresencePenalty    *float64 `json:"presence_penalty,omitempty"`
N                  *int     `json:"n,omitempty"`
LogitBias          map[string]float64 `json:"logit_bias,omitempty"`
Logprobs           *bool    `json:"logprobs,omitempty"`
TopLogprobs        *int     `json:"top_logprobs,omitempty"`
```
Add a helper `func (r *OpenAIChatRequest) StopSequences() []string` that
normalizes `Stop` (nil→nil, string→[]string{s}, []any/[]string→[]string,
ignoring non-strings). Reuse it everywhere stop is needed.

## 2. Anthropic translation (`internal/adapter/adapter.go` ToAnthropic)

- Set `out.StopSequences = req.StopSequences()` (AnthropicMessagesRequest
  already has StopSequences; byok.go/anthropic.go already forward it).
- Map reasoning → extended thinking: when `req.ReasoningEffort` or
  `req.Reasoning` requests thinking, set `out.Thinking` to
  `{type:"enabled", budget_tokens:N}` where N derives from effort
  (low≈1024, medium≈4096, high≈8192 — clamp to `< out.MaxTokens`; if
  out.MaxTokens <= budget, raise MaxTokens to budget+the original cap or a
  safe minimum). Only when thinking is actually requested; otherwise leave
  Thinking nil. Match the existing Thinking shape used on the /messages path
  (internal/adapter/messages.go req.Thinking).
- `top_k`: add `TopK *int json:"top_k,omitempty"` to AnthropicNativeRequest
  (messages.go) AND AnthropicMessagesRequest (types.go), and forward it
  through MessagesToAnthropic and every Anthropic outbound body
  (anthropic.go, byok.go, gcp.go/vertex, openrouter Anthropic path). OpenAI
  chat has no top_k, so this is only for the native /messages surface —
  parse it there so it stops being silently ignored.

## 3. OpenAI-compatible passthrough (`internal/llm/byok.go` openAICompatibleRequest)

Add fields + forward from the inbound request (these providers accept them
verbatim): `seed`, `frequency_penalty`, `presence_penalty`, `logit_bias`,
`logprobs`, `top_logprobs`, `n`, `stop`. Wire them in
`buildOpenAICompatibleRequest` from the parsed OpenAIChatRequest. Keep the
existing max_tokens/max_completion_tokens per-provider logic intact.

## 4. Gemini (`internal/llm/vertex_gemini.go` vertexGeminiPayload generationConfig)

Add to generationConfig when present on the request:
- `stopSequences` from `req.StopSequences()`
- `candidateCount` from `req.N` (only if >1; leave default otherwise)
- `frequencyPenalty` / `presencePenalty` from the request
- `seed` from `req.Seed`
- `topK` — Gemini supports generationConfig.topK; wire it if the request
  carries one (OpenAI chat has none, so this is for completeness / the
  Anthropic-native top_k when routed to Gemini — skip if not applicable).
Confirm exact JSON key names against ai.google.dev/api/generate-content.

## 5. `n` on Anthropic-only routes

Anthropic has no `n`. When `req.N != nil && *req.N > 1` and the resolved
provider is Anthropic-family (no candidateCount support), return a 400/501
AdapterError ("n>1 not supported for this model") rather than silently
returning 1 choice. Do NOT fabricate multiple choices.

## Tests (`internal/types`, `internal/adapter`, `internal/llm`)

- StopSequences() normalizes string, []string, []any, nil correctly.
- ToAnthropic sets StopSequences from stop (string and array forms).
- reasoning_effort=high on a chat request → out.Thinking enabled with a
  budget < MaxTokens; no reasoning → Thinking nil.
- openAICompatibleRequest carries seed/penalties/logit_bias/n/stop when set,
  omits them when absent (omitempty).
- vertexGeminiPayload emits stopSequences/seed/penalties when set.
- n>1 on an Anthropic route errors; n>1 on Gemini sets candidateCount.
